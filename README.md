
# OpenAIRE SoMEF Status Report

An HTML visualization for displaying research software metadata analysis results from the OpenAIRE project. 
This report presents findings on how research communities describe, manage, and share software metadata in 
their code repositories.

## Overview

This project analyzes **40,982 GitHub repositories** to understand software metadata practices 
across research communities. The analysis focuses on five research questions (RQs) examining 
various aspects of research software metadata and documentation.

## Research Questions

The report addresses the following research questions:

- **RQ1**: How do communities describe Research Software metadata in their code repositories?
- **RQ2**: What is the adoption of archival infrastructures across disciplines?
- **RQ3**: How do software projects adopt versioning?
- **RQ4**: How comprehensive is the metadata provided in code repositories?
  - RQ4-1: Do research projects include a description?
  - RQ4-2: What is the adoption of open licenses?
  - RQ4-3: How well documented are research projects?
- **RQ5**: What are the most common citation practices among communities?
